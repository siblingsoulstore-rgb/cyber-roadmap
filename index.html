By the end of Week 16 you should be able to

    Using AI without cheating yourself

    • Ask it to explain concepts at different levels, quiz you without giving answers, and review your code and write-ups.
    • Try a lab or CTF for 20–30 minutes first, and show your attempt before asking. Ask for a hint, not the solution. Don't copy code you can't explain.
    • Ask it to challenge your findings and spot false positives.
    • Never paste passwords, API keys, tokens, personal data or confidential evidence.

    The big picture

    Four 4-week phases, each building on the last. Don't skip Phase 1 even if it feels slow.

    PhaseYou will be able toPortfolio output
    1. FoundationsUse the Linux terminal, explain how the internet works, scan with Nmap, read packets in WiresharkLab setup post, Bandit write-ups, "visiting a website" report
    2. OffenseWrite small Python tools; find and exploit OWASP Top 10 bugs in practice appsPython tools on GitHub, PortSwigger lab notes, own-app security review
    3. InvestigationTrace scams with OSINT; analyze disk images, memory dumps and logsMock fraud investigation, forensics write-ups
    4. ProofSolve beginner CTFs, pentest a practice machine, write a professional reportPentest report, CTF write-ups, resume
    Rule of thumb: 30% theory, 70% hands-on. If a week goes badly (quizzes, midsems, fests), shift the plan a week. Don't cram.

      Free Coursera certificates (via Financial Aid)

      Certificates aren't free by default. Financial Aid unlocks the full course and shareable certificate for free. Audit mode only gives you the videos.

      1. Open the course → Enroll → Financial aid available (not the free trial).
      2. Fill the form honestly: student status, why you need it, how it fits your career goal.
      3. Wait about 2 weeks. Starting a 7-day free trial meanwhile can cancel the application.
      4. For a Professional Certificate, apply for each course separately. Up to 10 applications can be active, so apply 2–3 at a time.
      Track your courses
        Don't overload: your 12 hours are already full. Use Google courses 1, 3, 4 in place of some Phase 1–2 theory videos, Infosec Forensics in place of some Phase 3 reading, and do the rest after Week 16. Labs and reports count more in interviews than certificates.

              • 
        
            • Electives: take Computer Networks and Operating Systems if your program allows.

            Resume formula: what you built or tested + tools + result. "Performed a black-box pentest of a web app using Burp Suite and Nmap; found 6 vulnerabilities including SQL injection and IDOR; wrote a 7-page report with fixes."

            Ethics and Indian law
            
      
            The only difference between an ethical hacker and a criminal is written permission.
            
      
            
        
            LawCoversWhy it matters
            
        
            IT Act, 2000 Sec 43Unauthorized access, downloading data, virusesLiability to pay compensation
            
        
            IT Act Sec 66Sec 43 acts done dishonestly or fraudulentlyUp to 3 years in jail and/or fine
            
        
            IT Act Sec 66C, 66DIdentity theft, cheating by impersonationCore to the scam cases in Phase 3
            
        
            DPDP Act, 2023Handling of personal dataKeep OSINT on real people ethical and proportionate
